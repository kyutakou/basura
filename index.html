What the system does

One dashboard for barangay staff. One text thread for residents.

SMS collection requests

Residents text waste type, preferred time, location, and designated pickup point. No internet required.

Schedule monitoring

Schedules are organized and displayed per area so residents know when the truck is coming.

Route and pickup points

Routes and designated pickup points appear in one view, including interior areas trucks cannot reach.

Resident notifications

Automatic SMS alerts for schedule changes, route updates, and pickup confirmations.

Reporting and recording

Every request and concern is logged so personnel can review and act on it.

Built for the looban

Households in narrow alleys register a pickup point that collection vehicles can actually reach.

From a text message to a planned route

  1. 1

    Resident sends a request

    By SMS or the web app: waste type, preferred time, location, and pickup point.

  2. 2

    Request is logged

    It appears on the barangay dashboard with a reference number and timestamp.

  3. 3

    Route and schedule update

    Personnel review incoming requests and adjust the day's route and pickup points.

  4. 4

    Resident is notified

    An SMS confirms the pickup window, so no one puts trash out too early.

Not every household has data. Every household has text.

Requests and notifications travel through a telco SMS gateway, so residents with basic phones or limited internet can still report waste and receive schedule updates.

Common questions

Do I need internet to send a pickup request?

No. Requests can be sent by SMS from any basic phone. The web app is available if you prefer a screen and have data.

Which areas are covered?

Barangay Gen. T. De Leon in Valenzuela City. The pilot does not cover other barangays, and route data is limited to this barangay.

Can I choose which type of waste gets collected?

Yes. You indicate the waste type (solid, liquid, organic, non-biodegradable, or hazardous) along with your preferred time, location, and designated pickup point.

Does BASURA replace segregation or the current collection service?

No. It is a monitoring and communication tool that supports the existing collection service. Segregation remains the responsibility of households and the barangay.

Who can see my requests?

Only authorized accounts approved by the system administrator: barangay officials, environmental personnel, and assigned waste collectors.
